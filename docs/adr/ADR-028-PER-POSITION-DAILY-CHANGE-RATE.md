# ADR-028：持仓表直接显示逐股今日涨幅与金额

## Status

Accepted; layout amended by ADR-029

**Date:** 2026-08-03（同日修订）

**Decider:** 产品所有者

## Context

首页已经计算并保留每只股票相对最近常规收盘价的今日盈亏金额与涨跌幅。产品所有者希望在每只股票同一行直接看到今日涨幅，并把其下方的“估算”替换为该股票具体增加或减少的金额，金额使用小字；同时要求为新增信息收紧第一列和表格左右留白，公司名称可以使用容易辨认的简称，例如把 `Amazon.com, Inc.` 显示为 `Amazon`。

首页仍需要同时回答累计持仓表现。新增逐股今日涨幅不能覆盖第四列累计浮动盈亏/收益率，也不能恢复“持仓 / 今日”模式切换。

ADR-029 后续保留本 ADR 的字段、简称和计算决定，但取代“在手机宽度内压缩五列及极窄时两列重排”的布局：名称/代码固定在左侧，其余列改为整表共享横向滑动。

## Decision

- 总资产 3 × 2 指标矩阵继续显示组合“今日盈亏”：金额为主值，组合涨跌幅为副值。
- 持仓表从四列扩展为五列：“名称/代码”“市值/数量”“估值价/均价”“盈亏/收益率”“今日涨幅”。
- 第四列继续固定显示累计浮动盈亏与持仓收益率；第五列主值直接显示领域已有的逐股 `estimatedDailyChangeRate`，下方小字显示同一结果的 `estimatedDailyPriceEffect` 格式化金额，不重复“估算”文案，也不提供模式切换。
- 逐股今日涨幅继续使用 ADR-024 的未舍入公式 `(valuationPrice - previousRegularClose) / previousRegularClose`。正值红色、负值绿色，并始终保留正负号。
- 金额使用与涨幅相同的红涨绿跌方向和显式正负号；CNY 模式按同一笔有效汇率折算金额，涨幅保持不变。
- 缺少有效估值价或最近常规收盘价时，第五列显示 `— / 暂无`，禁止用 `0` 补齐。IBKR USD 现金显示 `— / 不参与`。
- 公司可见名称只在展示层删除常见法律实体或证券类型后缀，包括 `.com`、`Inc.`、`Corp.`、`Corporation`、`Company`、`Ltd.`、`Common Stock`、`Class X Capital Stock`、`ETF` 和同类后缀。股票代码、规范标的键、IndexedDB 保存名称、复制资料和辅助技术完整名称保持不变。
- 表格字段顺序与两行数值结构保持不变；移动端宽度、固定列和横向浏览方式由 ADR-029 规定。
- 本决定只消费现有 ViewModel 字段，不新增领域公式、行情请求、IndexedDB 字段、云端状态或持仓写入。

## Consequences

### Positive

- 用户无需进入详情或切换模式即可横向比较每只股票的当日价格变化。
- 累计收益率和今日涨幅同时存在且列名分开，避免把成本收益与当日价格变化混为一个百分比。
- 展示简称为第五列腾出空间，同时保留完整名称作为数据与辅助技术真值。

### Trade-offs

- 第五列需要容纳百分比与金额两行；金额使用小字，极端大金额与文字放大仍需真实设备验证。
- 用户需要横向滑动才能查看后侧列；固定名称列、整表同步与手势兼容由 ADR-029 约束。
- 展示简称可能与 provider 完整公司名不同，必须保证股票代码始终可见且完整名称仍可被辅助技术读取。

## Amends

- 修订 ADR-020 的四列表结构为五列连续表格。
- 修订 ADR-021“首页保持四列表格”的界面描述；复制文本仍保留完整公司名称。
- 修订 ADR-025“逐股今日金额与涨跌幅不在当前首页展示”的部分：逐股今日涨幅和金额进入第五列；无独立入口和无模式切换继续有效。
- 扩展 ADR-027 的组合级今日盈亏展示：组合指标不变，逐股今日涨幅与金额同时进入持仓行。

## Verification

发布前必须证明：

- 正、负、零值和缺少前收盘价时，第五列百分比与小字金额分别显示正确符号、颜色和未知状态；
- 股票第五列的下方不再显示“估算”，页面级估算边界仍然可见；
- CNY 模式折算小字金额但不换算今日涨幅，且币种切换不改写 USD、持仓或行情真值；
- 现金第五列明确显示“不参与”，现金变化不影响任何股票今日涨幅；
- 公司简称只改变可见文本，完整名称仍用于辅助技术、持仓操作、复制资料和底层身份；
- 320、375、390、430 CSS px 与 200% 文字下，表内横向滚动按 ADR-029 工作，页面本身没有非预期横向滚动、重叠或裁切；
- 完整自动化门禁通过，真实 iPhone 五列布局与 VoiceOver 另行验收。
