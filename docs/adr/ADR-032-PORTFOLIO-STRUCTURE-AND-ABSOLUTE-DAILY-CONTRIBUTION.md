# ADR-032：组合结构使用已定价总资产，今日贡献使用绝对变化总量

## Status

Accepted

**Date:** 2026-08-09

**Decider:** 产品所有者

## Context

首页已经回答总资产、累计盈亏、今日盈亏和逐股今日变化，但用户仍需要判断风险集中在哪里，以及当天波动主要由哪些股票推动。结构占比和今日贡献看似都可以显示百分比，分母却不同：结构描述当前资产分布；贡献描述当日绝对波动的来源。若使用剩余成本替代缺价股票市值、把缺失变化补为零，或以净盈亏作为贡献分母，结果会被缺价或正负抵消扭曲。

## Decision

- 组合结构分母固定为“有有效估值价的股票市值之和 + 当前现金本金”。单只股票结构占比等于其未舍入市值除以该分母；现金占比等于现金本金除以该分母；Top 1、Top 3、Top 5 集中度按未舍入股票市值降序求和后除以同一分母。
- 缺少有效估值价的股票不以剩余成本、零或上一展示舍入值代替市值，不进入结构分母，其占比不可计算。只要存在这类股票，结构结果必须标记为部分口径并说明未计价股票数量；不能把可计算占比称为完整组合占比。
- 单股今日变化金额继续使用 `currentQuantity × (valuationPrice - previousRegularClose)`。现金、NAV 和未入账利息不参与今日变化或贡献。
- 组合今日净额只在每只股票都同时有有效估值价和最近常规收盘价时计算；任一股票缺失时，净额不可用，缺失项不得以 `0` 补齐。
- 今日绝对变化分母为所有可计算股票的 `abs(单股今日变化金额)` 之和。单股绝对贡献占比等于 `abs(单股今日变化金额) / 今日绝对变化分母`。该占比描述波动贡献大小，不携带方向；方向由单股变化金额和最大正/负贡献单独表达。
- 当只有部分股票可计算时，可以显示可计算子集的绝对贡献排序和覆盖数量，但必须明确是部分口径；不能显示完整组合今日净额。当绝对变化分母为 `0` 时，所有贡献占比不可用，不能制造 `0%` 或平均分配。
- 所有结构和贡献计算使用未舍入 USD 真值。人民币模式只把 USD 金额按同一有效汇率派生显示，结构占比、贡献占比和排序不变。
- 该能力是首页的次级只读详情，不新增行情源、持仓写入、投资建议或自动调仓。

## Consequences

### Positive

- 结构占比与首页总资产使用同一资产口径，现金不会在结构分析中消失。
- 绝对贡献不会被上涨与下跌相互抵消，能稳定回答“哪些股票推动了今天的波动”。
- 缺价和缺少前收盘价都被显式保留为不完整状态，不会生成看似精确的错误结果。

### Negative

- 部分定价时，已显示的结构百分比之和可能接近 100%，但只代表已计价股票与现金；界面必须持续披露范围。
- 组合净变化接近零时，正负股票仍可能各有较高绝对贡献；用户需要同时阅读方向和占比。
- 全部可计算变化都为零时没有有意义的贡献占比。

### Neutral

- Top N 只衡量股票集中度，但分母包含现金；当股票不足 N 只时使用实际可计价股票数量。
- 该详情复用既有组合与今日变化真值，不改变首页 2 × 2 指标或五列表口径。

## Alternatives Considered

- **用剩余成本替代缺价股票市值：** 拒绝。成本不是当前资产价值，会混淆结构与投入。
- **缺失价格或前收盘价按零处理：** 拒绝。会伪造完整性并压低缺失股票的风险贡献。
- **用组合今日净额作贡献分母：** 拒绝。正负抵消后分母可能接近零，使占比失真或不可解释。
- **只展示持仓数量或成本占比：** 拒绝。不能回答当前资产暴露与当日波动来源。
- **为洞察增加新的行情或分析服务：** 拒绝。当前需求可由既有未舍入真值确定性派生，新增来源只扩大故障与隐私边界。
