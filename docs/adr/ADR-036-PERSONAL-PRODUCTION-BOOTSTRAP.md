# ADR-036：个人生产版一次性启动迁移

- 状态：Superseded by ADR-040
- 日期：2026-08-11
- 决策者：产品所有者
- 修订：ADR-031 的通用恢复入口保持不变；本 ADR 只增加固定个人 Production 例外

> `[用户确认 2026-08-15]` 本 ADR 已由 ADR-040 全面取代。固定客户端载荷、一次性标记逻辑和 Production 自动恢复路径已移除；本文只保留为历史决策记录。

## 背景

产品所有者已经在当前开发会话提供聚合 current 仓位和 IBKR USD 现金，并明确要求完成部署后直接看到效果。现有生产仍是公开 Vercel PWA，持仓真源位于每个浏览器来源的 IndexedDB；Vercel 无法直接写入目标 iPhone 的数据库。

产品所有者明确接受单人个人版本为零操作效果承担去身份化聚合值可从公开客户端检索的风险。姓名、真实账户号、原始月结单和逐笔交易不在授权范围内，继续排除。

## 决策

1. Production 客户端内置固定、去身份化的 27 只聚合 current 仓位和 IBKR USD 现金；开发和测试 runtime 不自动执行。
2. 独立 `localStorage` 键作为一次性完成标记；标记存在时整次迁移 no-op，标记与历史库解耦。
3. 标记不存在时读取 current 股票与现金。两者同时为空才复用 ADR-031 的 `restoreCurrentBackup()` 事务写入 revision 1 current；任一已有记录都禁止恢复、合并或覆盖。
4. 本迁移不打开历史 repository，不解析或导入 NAV，也不自动记录历史观察点。
5. 无论 current 是否为空，本次检查结束后都尽力写入完成标记；以后删除 current 时启动不得重新恢复。一般用户的 JSON v2 恢复规则保持不变。

## 结果

- 目标生产来源第一次加载即可显示 current 组合；已有 iPhone current 不受覆盖。
- 公开 bundle 包含去身份化聚合资产数值。当前版本没有认证或访问控制；知道生产 URL 的第三方理论上可以检查这些数值。
- 该能力不可配置、不读取聊天、不连接券商、不提供云同步，也不成为通用无人值守恢复产品。
- 若未来增加认证或私密服务端配置，应移除客户端固定载荷；已写入 IndexedDB 的 current 与既有历史数据仍按各自真源规则保留。

## 验证

- 严格 backup 解析与 27 只仓位/现金真值；
- 空 current 原子恢复；
- 非空 current 零改动；
- 独立完成标记与第二次运行 no-op；
- NAV、姓名、真实账户号和逐笔交易排除扫描；
- Production build 与目标手机宽度 smoke。
