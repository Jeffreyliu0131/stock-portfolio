# ADR-038：持仓资料提供普通复制与 ChatGPT 两个目标

## Status

Accepted

**Date:** 2026-08-12

**Decider:** 产品所有者

## Context

ADR-033 把所有持仓资料的最终范围选择统一为“复制并打开 ChatGPT”。该路径适合直接把资料交给 ChatGPT，但用户也会把同一份资料粘贴到其他 AI、备忘录或任意应用。强制跳转会打断普通复制任务，并让本来不需要离开 PWA 的操作进入额外的外部数据边界。

产品所有者选择在现有“更多操作”底部面板中并列两个清晰入口，保持当前 ChatGPT 快捷路径，同时恢复一个不会跳转的普通复制路径。范围、文本和业务计算不分叉。

## Decision

- “更多操作”在“持仓资料”分组下提供两个入口：
  - “仅复制持仓资料”：打开现有范围菜单；最终选择只写入系统剪贴板，并留在当前 PWA。
  - “复制并打开 ChatGPT”：打开同一范围菜单；最终选择先调用剪贴板，再通过 `https://chatgpt.com/?prompt=` 打开同一文本的待发送 Prompt。
- 两个入口共享 `PortfolioCopyScope`、同一个当前页面内存复制源和同一个 USD 事实文本生成器。前 5、前 10、全部、单只、排序、字段、缺价、现金、组合摘要、仓位与排名完全一致；不得为不同目标生成两份内容。
- 单只股票操作菜单同样提供“仅复制这只持仓资料”和“复制并打开 ChatGPT”，两者都使用相同单只范围与组合上下文。
- 普通复制不得构造 ChatGPT URL、触发外部导航、打开系统分享面板或调用 OpenAI API。剪贴板成功后显示短暂 Toast“已复制，可粘贴到其他应用”；失败时显示同一文本的手工复制弹层。
- ChatGPT 路径继续遵守 ADR-033：剪贴板与 URL 复用同一字符串，Prompt 完整编码、保持待发送、不自动发送、不接收回答；成功 Toast 为“已复制并打开 ChatGPT”，预填或路由失败时保留剪贴板/手工粘贴路径。
- 底部面板使用全宽贴底白色圆角层，普通复制为中性行，ChatGPT 行使用浅蓝强调；两条入口下明确说明“生成同一份 USD 资料，均不会自动发送”。刷新、数据安全与恢复、导出数据副本继续位于上方工具分组。
- 两条路径都不得修改 IndexedDB、持仓、行情/汇率缓存、schema、同步状态或计算结果，也不得把复制文本写入本产品日志、分析事件或错误回报。

## Consequences

### Positive

- 用户可以按实际目标选择是否离开 PWA，不再为粘贴到其他应用承担一次无关跳转。
- ChatGPT 快捷路径仍是一条明确的一步入口；已有 Prompt、剪贴板和手工回退能力不退化。
- 文本生成与范围 contract 只有一套，避免两个入口随时间产生字段或计算差异。
- 普通复制不把持仓资料放入外部 URL，隐私边界小于 ChatGPT 路径。

### Negative

- “更多操作”和单只菜单各增加一个可见动作，面板信息密度上升。
- 用户需要在两个目标中做一次选择；名称、视觉强调与 Toast 必须持续区分，避免误认为普通复制会跳转。

### Neutral

- 本决定只改变交付目标与入口视觉，不改变复制文本、资产计算、行情、USD/CNY、现金、JSON、IndexedDB 或部署架构。
- 系统分享面板仍不进入本次范围；“任意应用”通过标准剪贴板粘贴完成。

## Alternatives Considered

### 保留单一 ChatGPT 入口

入口最少，但不能满足复制到其他应用且留在当前页面的已发生场景。

### 一个主按钮加目标下拉菜单

视觉更紧凑，但目标含义被隐藏，移动端多一层选择，且更容易沿用上次目标产生意外跳转。

### 使用系统分享面板选择任意应用

可以暴露更多目标，但目标列表与粘贴行为受系统和已安装 App 影响，也会改变现有剪贴板工作流；当前不采用。

## Verification

- 组件测试覆盖“更多操作”和单只菜单的两个入口、相同范围 contract、目标参数、目标专属 Toast、手工回退和焦点返回。
- 普通复制测试固定只调用剪贴板处理器，不调用 ChatGPT URL 构造或导航；ChatGPT 交付既有调用顺序与编码测试继续通过。
- 390 × 844 视觉验收把选定参考图与本地生产构建并排比较；另覆盖 320 px 无横向溢出、底部安全区、范围菜单、单只菜单、Escape 与控制台错误。
- 真实 iPhone Safari 与主屏幕 PWA 分别验证普通复制可粘贴到其他应用且不离开 PWA，以及 ChatGPT App/网页接管、待发送、长文本和手工回退。设备验证只使用合成资产。

## Amends

本 ADR 修订 ADR-033 中“所有最终选择都必须打开 ChatGPT、不保留只复制范围”的决定。ADR-021 与 ADR-026 的范围、排序、字段和事实文本继续有效；ADR-033 的 HTTPS URL、剪贴板复用、待发送、外部数据边界及真实 iPhone 验证规则只适用于用户明确选择的 ChatGPT 入口。
