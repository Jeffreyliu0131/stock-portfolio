# ADR-021：本机复制结构化持仓资料

## Status

Amended by ADR-023, ADR-026, ADR-028, ADR-033 and ADR-038

**Date:** 2026-08-01
**Decider:** 产品所有者

## Amendment 2026-08-03

ADR-028 把首页四列持仓表扩展为五列并加入逐股今日涨幅。复制范围、字段和完整公司名称保持不变；展示简称只作用于首页可见第一列。

## Amendment 2026-08-09

ADR-033 修订本 ADR 的交付边界：前 5、前 10、全部或单只的最终选择都继续保留同一文本的剪贴板副本，但不再由用户自行切换 App。页面会通过 `https://chatgpt.com/?prompt=` 打开 ChatGPT，并把同一文本预填为待发送 Prompt；App 未接管时回落网页，失败时保留手工粘贴。不得自动发送、调用 OpenAI API 或把回答带回 PWA。下文“不跳转”和“一键直达不在范围内”只记录 2026-08-01 的原始决定，已由 ADR-033 取代。

## Amendment 2026-08-12

ADR-038 把交付拆为两个显式目标：普通复制恢复本 ADR 的“写入剪贴板并由用户粘贴到任意应用”，ChatGPT 入口继续遵守 ADR-033。两个目标复用本 ADR 的范围与同一文本生成器。

## Context

用户会把组合或单只持仓资料粘贴到自行选择的 AI 对话中咨询。页面截图会丢失结构、行情元数据和缺价语义，直接连接指定机器人、跳转第三方 App 或上传服务端又会扩大鉴权、隐私和交付边界。

产品所有者确认首版只需要把足够完整的结构化文字写入系统剪贴板：不直连 AI、不跳转、不调用系统分享、不生成图片，也不附带预设问题。用户自行切换到目标 App 粘贴。

## Decision

- 首页账户导航增加“复制”操作；范围包含按未舍入市值降序的前 5、前 10、全部和单只持仓。与全部范围重复的前 5 或前 10 选项不显示。
- 长按单只持仓的现有操作菜单增加“复制这只持仓资料”快捷入口。
- 单只文本包含组合总览、该标的完整聚合数据、仓位占比和市值排名，但不展开其他标的。
- 文本只包含事实数据，不包含 AI 提问或投资建议。组合和持仓字段包含数量、成本、估值、盈亏、收益率、仓位占比、排名以及真实行情来源、类型和时间。
- 缺价保持“暂无有效价格/无法计算”，不回退为 `0`。仓位占比使用未舍入市值除以未舍入的已定价总市值，之后才展示舍入。
- 文本生成只使用当前页面对应的内存快照和行情解析结果，不从格式化 UI 文本反向解析，也不在点击后重新读取 IndexedDB。
- 浏览器在用户点击处理器中、任何 `await` 之前调用 `navigator.clipboard.writeText()`。写入失败或不可用时显示只读文本框供手工全选复制。
- 复制过程不调用 Next.js API、不上传 Vercel、不改变 IndexedDB schema 或任何持仓记录，也不引入新的第三方依赖。

## Consequences

- 用户可以把一致、可解析的持仓上下文粘贴到任意目标，不受某个 AI 或聊天 App 绑定。
- 剪贴板会短暂包含私人资产数据；界面明确说明内容范围和不上传边界，离开 App 后由用户决定粘贴目标。
- 首页继续保持紧凑四列表格；详细行情元数据只进入用户主动复制的文本，不重新塞回每一行。
- 真正的一键直达机器人、截图、长图、分享面板和服务端 AI 分析均不在本决定范围内。

## Verification

- 纯函数测试覆盖全部、前 5、前 10、单只、相同市值稳定排序、碎股、大金额、部分/全部缺价、上一有效价、仓位占比和排名。
- 浏览器边界测试验证剪贴板写入在异步等待前同步调用，并覆盖不可用和拒绝后的手工回退。
- 首页组件测试覆盖动态范围、单只选择、长按快捷入口和手工复制文本框。
- `[实现事实 2026-08-01]` TypeScript、29 个测试文件中的 248 项测试、领域构建和 Next.js 生产构建完整门禁通过；合成 11 只持仓的 320/390/430 px 与 200% 根字号浏览器检查已通过。真实 iPhone Safari 与主屏幕 PWA 的系统剪贴板粘贴仍待验证。
