# ADR-025：今日涨幅进入总资产指标矩阵

## Status

Amended by ADR-027 and ADR-028

**Date:** 2026-08-02

**Decider:** 产品所有者

## Amendment 2026-08-03

ADR-028 保留无独立今日入口、无“持仓 / 今日”模式切换和第四列固定累计盈亏的决定，但修订“逐股今日涨幅与金额不在首页展示”：持仓表新增第五列，直接显示逐股今日涨幅与小字今日盈亏金额。

## Context

ADR-024 首版在总资产数字下方增加独立“今日变化”金额条，并让持仓表通过“持仓 / 今日”切换显示逐股今日变化。产品所有者确认今日信息无需独立入口或列表模式，只需在总资产下方的指标矩阵直接看到组合今日涨跌幅；原“定价覆盖”指标可以移除。

首页仍需保留组合今日变化金额，满足此前“像券商一样看今天变化金额”的目标，但金额与涨跌幅应合并在同一个低层级指标格，不与总资产一级数字竞争。

## Decision

- 总资产 3 × 2 指标矩阵移除“定价覆盖”，在原位置显示“今日涨幅”。
- “今日涨幅”主值使用 ADR-024 定义的 `portfolioEstimatedDailyChangeRate`；副值使用 `portfolioEstimatedDailyPriceEffect`，保留正负号并标注“估算”。
- 总资产一级数字下方不再显示独立今日变化条；持仓工具栏不再显示“持仓 / 今日”切换。
- 持仓表第四列固定显示累计浮动盈亏与持仓收益率；逐股今日金额与涨跌幅继续保留在领域和 ViewModel 中，不在当前首页展示。`[已由 ADR-028 取代]`
- 任一股票缺少有效估值价或前一常规收盘价时，组合今日涨幅与金额都显示 `—`，不得用部分结果或 `0` 补齐。
- IBKR USD 现金不参与组合今日变化分子或前收市值分母。组合只有现金时，“今日涨幅”显示 `—`，副值说明“现金无价格变化”。
- USD 是金额计算真值；人民币模式只折算今日变化金额，今日涨跌幅保持不变。
- 正值红色、负值绿色，并始终保留正负号。指标格提供同时包含涨跌幅与估算金额的辅助技术名称。
- 本决定不改变行情选择、领域公式、IndexedDB、备份、复制、排序、成本或持仓真值。

## Consequences

### Positive

- 用户无需进入详情或切换列表即可在总资产矩阵读取今日涨跌幅和金额。
- 首页减少一个独立信息条和两个切换按钮，持仓表保持稳定的累计收益口径。
- 今日指标与成本、累计盈亏、资产项目和币种处于同一层级，总资产仍是唯一一级数字。

### Trade-offs

- 首页不再直接显示逐股今日变化；需要该能力时必须另行确认新的详情方案。
- 总览不再显示数字化定价覆盖；缺价仍通过“已定价市值/已定价部分盈亏”、持仓行“暂无价格”和组合今日指标 `—` 诚实表达。
- 今日涨幅格同时承载百分比和金额，需要在窄屏、200% 文字和 VoiceOver 下单独验证。

## Amends

- 修订 ADR-020 的 3 × 2 指标矩阵：以“今日涨幅”替换“定价覆盖”。
- 修订 ADR-024 的 UI 展示：保留计算与数据边界，移除独立金额条和逐股切换。
- ADR-008、ADR-016、ADR-022 与 ADR-023 的 USD/CNY、行情和现金规则保持不变。

## Verification

`[实现事实 2026-08-02]` 首页指标格、持仓表固定口径、正负/缺失/现金/CNY 和辅助描述自动化已实现；35 个测试文件中的 299 项测试、TypeScript、领域构建和 Next.js 生产构建全部通过。真实市场时段和 iPhone 尚未验证。

发布前必须证明：

- 指标格主值来自未舍入组合今日涨跌幅，副值来自未舍入 USD 今日变化金额并在展示层舍入；
- 正、负、零、缺少前收、部分缺价、现金与 CNY 场景符合完整性和配色规则；
- “定价覆盖”、独立今日变化条和“持仓 / 今日”切换均不再出现在首页；
- 持仓第四列始终显示累计盈亏/收益率，移除切换不改变持仓操作或数据；
- 320–430 CSS px、200% 文字和 VoiceOver 下，百分比、金额与辅助描述完整可读且无关键横向溢出。
