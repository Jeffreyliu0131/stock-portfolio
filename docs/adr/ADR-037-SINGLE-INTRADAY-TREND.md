# ADR-037：首页只保留今日走势

## Status

Accepted（由 ADR-040 修订）

`[修订 2026-08-15]` 历史能力停用、`/history` 重定向和既有历史数据保留继续有效。本 ADR 中保留个人 Production current 启动迁移的条款已由 ADR-040 取代。

`[修订 2026-08-23]` 首页继续只保留“今日走势”，但删除趋势图下方“按当前股数估算 · 现金不参与”的重复小字。ADR-034 的计算、现金口径、完整性与估算边界不变，并继续在 2 × 2 今日指标和必要状态中表达。

**Date:** 2026-08-12

**Decider:** 产品所有者

## Context

产品所有者在试用六档组合收益后确认，现有多账户资料无法形成足够完整、可直接使用的长期账户曲线；继续保留周期按钮、历史导入和部分历史线会增加操作负担，也让首页难以理解。当前真实且可持续提供的数据是 ADR-034 定义的 Alpaca SIP 15 分钟日内条形和本机 current 持仓。

## Decision

- 首页趋势只保留一条“今日走势”，不显示 `1D / 1W / 1M / 3M / 1Y / ALL` 周期选择器。今日线继续完全遵守 ADR-034 的市场数据、当前数量、现金、完整性和隐私规则。
- 首页标题和趋势说明使用“今日”与“按当前股数估算”；2 × 2 今日盈亏、总资产、五列持仓、USD/人民币和既有操作保持不变。
- 更多操作和空状态删除历史收益入口；直接访问 `/history` 重定向首页，不显示粘贴、文件选择、预览或未来事件表单。
- `PortfolioController` 不打开历史 repository、不查询 Modified Dietz 系列，也不在行情刷新后自动记录 NAV。
- 已经写入设备独立历史 IndexedDB 的记录不删除、不迁移、不并入 current。历史解析、存储、图表类型和测试可以作为停用代码保留，但不得被首页或后台调用；重新启用需要新的产品决定。
- `[由 ADR-040 取代]` 个人 Production 固定启动载荷和自动 current 恢复已移除；新来源保持空组合，既有 current、历史数据和旧标记不改写。

## Consequences

- 首页只有一个可理解且有市场数据支持的时间范围，不再要求用户导入资料或解释部分历史。
- 既有本机历史数据不会因功能撤回而丢失；停用模块会暂时增加少量代码维护成本。
- 当前产品不提供完整账户长期收益。不得把今日当前持仓估算描述成券商真实账户回报。

## Verification

- 组件测试证明首页只显示今日口径，不存在长期周期按钮或历史链接。
- Controller 测试证明运行链路不打开历史 repository 或写入 NAV。
- `/history` 路由测试或生产 smoke 证明最终回到首页。
- Production 启动回归证明空 current 不自动恢复、不写标记或历史；已有 current 继续正常读取。
- 完整门禁与移动浏览器检查证明首页、趋势交互和现有持仓路径无回归。

## Supersedes and amends

- 取代 ADR-035 的产品运行路径与可见范围；ADR-035 仅保留为历史设计和既有数据安全边界。
- 修订 ADR-034：其 `1D` 算法成为首页唯一趋势，不再由长期范围补充。
- 原对 ADR-036 的修订已由 ADR-040 取代；Production 不再运行固定 current 启动迁移。
