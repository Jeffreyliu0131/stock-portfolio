## 当前结论

`[用户确认 2026-08-20；当前最高优先级修订]` 新 Production 使用 OpenAI Sites，owner-only 且必须 ChatGPT 登录。资产 current 以 D1 按稳定 Sites user id 隔离，同一账号跨设备读取同一组合；邮箱不持久化。旧 Vercel IndexedDB 原样保留，因 origin 隔离只能先导出 JSON v2/v3，再在空 Sites 账号中严格预览、二次确认和恢复。绑定决定见 ADR-045；它取代 ADR-012/014 的现行本地真值与产品页面托管结论，以及 ADR-043 的公开免登录决定。

`[用户确认 2026-08-20；当前最高优先级修订]` Sites 不能直连 Alpaca、ECB 和 DeepSeek，因此现有 Vercel 保留为固定 provider-only 后端。Sites 独占 UI、登录与 D1 current；浏览器仅在精确 Sites origin 下以无 credentials CORS 请求固定 Vercel origin，CSP 只新增该 `connect-src`。Vercel 不保存账号 current，行情仍是约 15 分钟延迟。绑定决定见 ADR-046；OQ-020 已关闭。

`[用户确认 2026-08-22]` owner-only Sites 的安装图标不能依赖受保护同源静态路径。Sites URL、App identity、登录和 D1 不变；favicon、`apple-touch-icon` 与 manifest 图标改为从固定 Vercel `/icons/` 匿名读取版本化 PNG，Sites CSP `img-src` 只增加该 origin。provider API 的精确 CORS 与无 credentials 不变。绑定决定见 ADR-047；OQ-021 已关闭。

`[用户确认 2026-07-30 至 2026-08-13；2026-08-20 修订]` 产品不提供自由券商账号管理，首页始终按标的合并并优先显示总仓位。未启用 v4 时继续使用旧快照录入、修改、加仓和删除；确认双券商校准后，股票写操作改为固定 IBKR/moomoo 来源的买入、卖出和校准，底层分券商维护子持仓与现金，但首页不展开券商股票拆分。普通复制和复制并打开 ChatGPT 在两种 current 模式中都保持只读。

`[用户确认 2026-07-31；2026-08-03、2026-08-20 修订]` P0 支持 Alpaca 可解析的 USD 美国上市股票与 ETF；Sites 账号 D1 是 current 真值，IndexedDB 只保留草稿与可替换缓存；首页可把 current 手动导出为 JSON，导出和后续修改不得弄丢现有数据。Web runtime 使用 Next.js App Router + React，Service Worker 与完整离线延后。估值跟随盘前、常规盘、盘后和 24/5 隔夜时段：前三者使用 Alpaca `delayed_sip`，隔夜使用 `overnight`；约 15 分钟延迟在页面级只披露一次。首页采用 Futu 账户页式总览与五列持仓表：第四列显示累计盈亏/收益率，第五列显示逐股今日涨幅与小字今日盈亏金额；不显示逐行市场时段、行情日期时间、过期、上一有效价或隔夜提醒，缺价和请求故障仍明确呈现。

`[用户确认 2026-08-08]` 首页删除无功能的账户身份区、资产/持仓/现金导航和资产类别假标签。顶部只保留总仓位、币种切换和更多操作；总资产下使用 2 × 2 核心指标；底部只保留“录入资产”，再选择股票或 IBKR 现金。五列整表横滑完整保留；股票行点按或长按均打开操作，横滑后抑制误触点击。绑定决定见 ADR-030。

`[用户确认 2026-08-09；2026-08-12 修订]` 首页进一步按 Robinhood 高级资产页升级：总资产、今日收益、趋势与 2 × 2 指标位于连续纯黑英雄区，浅色连续持仓表与既有操作语义保留。趋势只显示由 Alpaca Historical Bars 真实 SIP 15 分钟收盘点和当前持仓数量估算的“今日走势”；不显示长期周期按钮、历史菜单入口或历史导入页。绑定决定见 ADR-034 与 ADR-037；ADR-035 的运行路径已被取代。

`[用户确认 2026-08-11；2026-08-12、2026-08-15、2026-08-20 修订]` 固定个人 Production 启动载荷和自动恢复路径已移除。新 Sites 账号保持空组合，只能手工录入或使用 JSON v2/v3 空账号恢复；旧 Vercel origin 中的 current、独立历史数据库和旧完成标记不删除、不迁移、不改写。ADR-040 取代 ADR-036，ADR-045 取代新来源的本地 current 结论。

`[用户确认 2026-08-01；2026-08-09、2026-08-12 修订]` 首页把前 5、前 10、全部或单只聚合持仓资料分为两个明确入口：“仅复制持仓资料”写入系统剪贴板并停留在 PWA；“复制并打开 ChatGPT”复制同一文本后通过 `https://chatgpt.com/?prompt=` 预填待发送 Prompt。两条入口复用相同 USD 事实文本、范围、未舍入排序和单只组合上下文，均不自动发送或调用 OpenAI API；失败时保留目标对应的手工回退，成功只显示短暂 Toast。绑定决定见 ADR-038。

`[用户确认 2026-08-03]` 复制资料实际用于粘贴给用户自行选择的 AI 获取建议。文本使用组合摘要与紧凑持仓表，只保留会改变 AI 判断的资产、成本、盈亏、现金、仓位、范围覆盖和持仓数据；逐股行情排障元数据改为组合级延迟/价格时间范围与必要例外标记，不预设 AI 提问。

`[用户确认 2026-08-02]` 首页提供 USD / 人民币模式切换。USD 继续作为持仓、成本、行情、录入和复制资料真值；人民币金额从未舍入 USD 金额派生，只作当前汇率下的估算，不建立第二套成本或汇兑盈亏。汇率优先使用 Alpaca 最新 `USDCNY` 中间价；Alpaca 未配置或不可用时使用欧洲央行每日参考交叉汇率。汇率无效或超过 7 天时继续显示 USD；上一有效汇率保留真实来源元数据。

`[用户确认 2026-08-03；2026-08-08 修订]` 首页不设置独立今日入口或持仓表模式切换。2 × 2 核心指标中的“今日盈亏”主值是整个股票组合的估算金额，副值是组合涨跌幅；其他三格为累计浮动盈亏/持仓收益率、股票剩余成本和现金本金。第四、五列口径不变；现金不参与今日盈亏，缺值不以零补齐。

`[用户确认 2026-08-03；2026-08-08 修订]` 持仓表采用固定名称/代码列加共享横向滚动：表头、全部股票行与 IBKR USD 现金行共用一个滚动位置，从持仓区任意一行起手都能左右查看数据；页面上下滚动和股票点按/长按继续可用，横向移动取消待触发长按并抑制随后点击。极窄宽度和文字放大不再把五列压缩或重排为两列。绑定决定见 ADR-029 与 ADR-030。

## 状态词

- `[用户确认 YYYY-MM-DD]`：用户直接表达，可作为验收依据。
- `[约束推导]`：满足用户确认目标所必需、但不是用户原话的规则。
- `[实现事实]`：代码、配置或验证结果反映的当前状态。
- `[外部事实 YYYY-MM-DD]`：有官方来源且可能随时间变化。
- `[建议]`：尚未由用户拍板的可逆方案。
- `[待确认]`：答案会改变产品、计算、数据或交付，不得自行决定。

旧文档中的 agent 建议、示例和现有代码结构都不自动等于用户确认。

## 同步规则

1. 产品决定先更新 PRD；公式只在领域文档定义；未决项只在开放问题维护。
2. 关闭问题时记录用户决定和日期，并同步受影响文档及 ADR。
3. 技术取舍通过新增或取代 ADR 记录，不静默改写历史。
4. 文档必须区分目标和已实现状态，不能把候选架构写成现状。
5. 外部服务能力只引用官方来源并记录核验日期。
6. 新增或移除运行模块、路由、持久化位置或外部写入时，同步 `10-MODULE-IMPLEMENTATION-MAP.md`；仅有代码、导出或测试不能证明模块已接入 P0。
